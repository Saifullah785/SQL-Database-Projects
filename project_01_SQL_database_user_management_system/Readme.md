# 📁 SQL Project — Flipkart Console-Based User Management System

## 📌 Project Overview

This is a Python + MySQL-based console application that provides a basic User Management System (Registration, Login, View Profile, Edit Profile, Delete Profile). The program simulates a simple "Flipkart-like" login system using a command-line interface and connects to a MySQL database named hit-db-demo.

## The project is designed to help beginners understand:

How to use Python to connect to a MySQL database using mysql.connector.

How to perform basic CRUD operations.

How to design a simple authentication system.

How to use OOP (Object-Oriented Programming) in Python for modular design.

## 🧩 Features

User Registration with name, email, and password.

Login System with email and password authentication.

View Profile (displays user ID, name, email).

Edit Profile (update name, email, or password).

Delete Profile (removes user data from the database).

Error handling for database connection and query execution.
